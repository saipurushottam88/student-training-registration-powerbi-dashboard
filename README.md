# 📊 Student Training Registration & Technology Analytics Dashboard

An interactive Power BI dashboard developed to analyze student training registrations and understand technology preferences and participation patterns across different academic years, sections, and other categories.

## 📌 Project Overview

This project transforms student training registration data into an interactive and visually appealing Power BI dashboard.

The dashboard provides a consolidated view of student participation and helps identify trends in technology preferences, academic year-wise registration, section-wise participation, and gender distribution.

The project demonstrates the complete data analytics workflow:

**Data → Data Preparation → Transformation → Visualization → Insights**

## 🎯 Objectives

- Analyze student training registrations.
- Understand technology stack preferences among students.
- Compare student participation across academic years.
- Analyze section-wise participation.
- Examine gender-wise distribution.
- Provide interactive filtering for better data exploration.
- Present meaningful insights through an interactive dashboard.

## 🛠️ Tools & Technologies

- **Microsoft Excel** – Data preparation and structuring
- **Power Query** – Data transformation and cleaning
- **Microsoft Power BI** – Data visualization and dashboard development

## 📊 Dashboard Features

The dashboard includes:

- 👨‍🎓 Student registration overview
- 📅 Year-wise student analysis
- 🏫 Section-wise participation
- 💻 Technology stack distribution
- 👥 Gender-wise analysis
- 🔎 Interactive slicers and filters
- 📈 Comparative visualizations
- 📌 KPI-style summary cards

## 💻 Technology Stacks Analyzed

The dashboard analyzes student registrations across technology tracks such as:

- Data Analytics
- Generative AI with Google Cloud
- Full Stack Development (MERN Stack)
- Salesforce Administrator with AI Agentforce
